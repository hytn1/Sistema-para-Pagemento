PROJETO AULA - RESTAURANTE BOM PRATO

Este projeto foi montado como Windows Forms com os controles criados no arquivo Designer.

Abra ProjetoAula.csproj no Visual Studio.

O Form1 já possui os componentes:
- Label
- TextBox
- CheckBox
- NumericUpDown
- Button
- Panel

Também existem os formulários Fechamento e DinheiroRecebido.

Importante:
Ao abrir Form1.cs no Visual Studio, use a opção "Exibir Designer" para visualizar e editar os componentes pela Caixa de Ferramentas.
